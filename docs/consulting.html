External Secrets

Resolve selected secrets from Vault; minimize secret duplication.

APISIX data encryption

etcd disk encryption

RECOVERY / 2.7

Encryption changes the restore plan

ETCDCTL_API=3 etcdctl \
 --endpoints=https://etcd.internal:2379 \
 --cacert=/secure/ca.pem \
 --cert=/secure/client.crt \
 --key=/secure/client.key \
 snapshot save /secure/backup/lab.db

Restore drill

Snapshot integrity → isolated restore → matching key recovery → Consumer auth test → documented rollback decision.

Never test restore directly against production etcd.

Acceptance includes recoverability of both data and encryption keys.

RECOMMENDATION

Choose the protection boundary first

The primary design decision is whether the acceptance criterion is no plaintext Consumer credentials in etcd, encrypted etcd storage, or both.

That decision determines APISIX compatibility research, key format, rollout sequence and recovery testing.
