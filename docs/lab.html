01 / GOAL

Secure by design

Protect config

Git review, validation, immutable revisions, rollback.

Protect secrets

Vault policies, scoped identities, secret rotation.

Protect management

Private Admin API, secured etcd, restricted network access.

Decision: define security acceptance criteria before deployment.

15 / CONFIG

Traditional: APISIX config.yaml

  role: traditional
  role_traditional:
    config_provider: etcd
  admin:
    allow_admin:
      - 127.0.0.1/32
    admin_key:
      - name: admin
        key: ${{ADMIN_API_KEY}}
        role: admin
  etcd:
    host:
      - https://etcd.internal:2379

Schematic only: etcd TLS client credentials and environment substitution must be validated for the pinned APISIX release.

17 / ROUTES

Standalone: apisix.yaml

  - id: hello
    uri: /hello
    methods: [GET]
    upstream:
      type: roundrobin
      nodes:
        "backend.internal:8080": 1
#END

Use an actual reachable backend. The trailing #END marker is required.

18 / VAULT

Vault policy + KV v2

# policy: apisix-read.hcl
path "kv/data/apisix/lab/admin" {
  capabilities = ["read"]
}

# operator CLI (authorized environment)
vault secrets enable -path=kv kv-v2
vault policy write apisix-read apisix-read.hcl
vault kv get -mount=kv apisix/lab/admin

Do not commit real credentials or use a Vault root token for the gateway.

20 / ANSIBLE

Ansible: validated config rollout

- hosts: apisix
  become: true
  tasks:
    - name: Deploy APISIX config
      ansible.builtin.template:
        src: config.yaml.j2
        dest: /etc/apisix/config.yaml
        owner: root
        group: root
        mode: "0640"
      no_log: true
      notify: reload apisix
  handlers:
    - name: reload apisix
      ansible.builtin.command: apisix test
      changed_when: false

Example validation task only: add an explicit reload after a successful test, and verify the package's real config path and service permissions.

21 / TESTS

Smoke and negative tests

# gateway route
curl -i http://127.0.0.1:9080/hello

# verify the admin endpoint is not public
# (run from an authorized test host)
curl -i --max-time 5 https://admin.internal:9180/apisix/admin/routes

# inspect Kubernetes rollout
kubectl -n apisix-lab get pods,svc
kubectl -n apisix-lab get events --sort-by=.lastTimestamp

Expected: route works; unauthorized Admin API requests are denied; no public Admin Service.
